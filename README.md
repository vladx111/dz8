## Описание работы

Во всех заданиях вычисления организованы с помощью цикла `for`. На блок-схеме
циклу соответствует блок «Повторение» (шестигранник с заголовком вида
«i = 1 … n, i + 1»): внутри блока задаётся начальное значение счётчика,
граница повторения и шаг. Тело цикла (вычисление очередного слагаемого или
множителя и накопление результата) выполняется, пока счётчик не дойдёт до
границы, после чего управление передаётся на вывод результата.

Общая блок-схема для всех заданий приведена в файле 

Структура каждой программы одинакова:
1. Ввод исходных данных с клавиатуры.
2. Инициализация накопителя: сумма `s = 0` или произведение `p = 1`.
3. Цикл по счётчику от начального до конечного значения.
4. В теле цикла — вычисление текущего элемента и накопление результата.
5. Вывод итогового значения.

## Перечень заданий

**1) Возведение в степень.** Вычисляется a^n: накапливается произведение
`p = p * a` на каждом шаге цикла от 1 до n.

**2) Произведение 1,1 · 1,2 · … · (1 + N/10).** Счётчик i меняется от 1 до N,
на каждом шаге множитель равен `1 + i/10`.

**3) Ряд 1/a + 1/(a(a+1)) + … + 1/(a(a+1)…(a+n)).** Очередной знаменатель
получается из предыдущего добавлением множителя `(a + i)`, поэтому слагаемое
пересчитывается рекуррентно: новое = старое / (a + i).

**4) Ряд 1/a + 1/a² + 1/a⁴ + … + 1/a^(2^n).** Показатель степени удваивается
на каждом шаге, поэтому очередное слагаемое получается возведением предыдущего
в квадрат: `t = t * t`.

**5) Знакопеременное выражение 1,1 − 1,2 + 1,3 − … (N < 10).** Условный
оператор не используется: знак чередуется умножением на переменную `sign`,
которая на каждом шаге меняется на противоположную (`sign = -sign`).

**6) Произведение a(a − n)(a − 2n)…(a − n²).** Счётчик i меняется от 0 до n,
множитель равен `a − i·n`.

**7) Ряд x − x³/3! + x⁵/5! − … + x¹³/13!.** Степень растёт на 2, факториал —
на два новых множителя, знак чередуется. Всё считается рекуррентно:
`term = -term * x * x / ((2k−2)·(2k−1))`, k от 2 до 7.

**19) Сумма sin(x) + sin²(x) + … + sinⁿ(x).** Один раз вычисляется
`sin(x)`, затем в цикле накапливаются степени: `t = t * sin(x)`, `s += t`.

**20) Сумма 1 + 1/2 + 1/3 + … + 1/N.** Слагаемое равно `1.0 / i`, i от 1 до N.

**21) Сумма N² + (N+1)² + … + (2N)².** Счётчик i меняется от N до 2N,
слагаемое равно `i * i`.

**22) Произведение (1 + sin(0,1)) · (1 + sin(0,2)) · … · (1 + sin(10)).**
Счётчик i от 1 до 10, множитель равен `1 + sin(i/10)`.

**23) Произведение a(a + 1)…(a + n + 1).** Счётчик i от 0 до n + 1,
множитель равен `a + i`.

**24) Факториал N! = 1 · 2 · … · N.** Считается в переменной типа `double`,
чтобы избежать целочисленного переполнения при больших N.

**25) Сумма 1¹ + 2² + … + N^N.** Каждое слагаемое вычисляется как
`pow(i, i)` и накапливается в переменной `double` — переполнения нет.

**26) Сумма 1^K + 2^K + … + N^K.** Слагаемое равно `pow(i, K)`, i от 1 до N;
результат — вещественный.

## Как собрать и запустить

Файл `lab8.c` компилируется любой версией компилятора C, например:
`gcc lab8.c -o lab8 -lm` (флаг `-lm` нужен для математической библиотеки).
После запуска программа показывает меню: вводится номер задания, затем
исходные данные этого задания, после чего печатается результат. Выход —
номер 0.
